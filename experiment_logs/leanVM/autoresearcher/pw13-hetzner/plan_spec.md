## Protocol spec (the documented identity replacement)

Constants: `UNIVARIATE_SKIP_K = 4` (compile-time, sweep 3..=5). Domain D = symmetric integer window of size 2^K (Jolt-style), nodes ∪ extended targets = `1 + (2^K−1)·d_max` points.

- **Front-loading**: every table joins round 0; table t (n_t vars) enters the combined target with static weight `w_t = 2^(n_max−n_t)`; after its n_t rounds its claim contributes `u/2` per round folded into `coeffs[0]` (prover side), so the verifier's `h(0)+h(1)=target` reconstruction is untouched; final combined value = `Σ_t s_t^final` (NO challenge-product k_t).
- **Round 0 (skip)**: all tables' first K fold variables (low K row bits; eq coords = last K entries of gkr_point, SHARED across tables) bound by one univariate round. Prover sends ONE combined coefficient vector `v'(X) = Σ_t w_t·v'_t(X)`, degree ≤ (2^K−1)·d_max (151 EF at K=4). Verifier checks `Σ_{z∈D} ê(z)·v'(z) == Σ_t w_t·s_t` where `ê(X)` = Lagrange interpolation over D of `eq(gkr_point[last K], bits(x))`; samples r_0; new target = `ê(r_0)·v'(r_0)` (Horner, no inversions).
- **Rounds 1..n_max−K**: existing combined rounds, degree ≤ 12, verbatim `h(0)+h(1)=target`.
- **Final check**: `target == Σ_t ê(r_0)·eq(gkr_suffix_t[..n_t−K], natural_prefix_t)·C_t(col_evals_t)` with `natural_prefix_t = reverse(linear_challenges[..n_t−K])`.
- **Opening claims**: per-table tensor weight `eq(natural_prefix) ⊗ Lagrange_{2^K}(r_0)` (tail on the last K natural coords = lowest K row bits); WHIR `SparseStatement` gains optional `tail`; shift (`is_next`) weight = shift-by-one of the tail-seeded eq vector.
